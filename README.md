# ようちえん クエスト（てんし ようちえん 75しゅうねん きねん）

園児が勇者になって 幼稚園の75年を旅する、やさしいドラクエ風RPG。
**HTML と JavaScript だけ**で動きます（Godot・ビルド作業は不要）。横画面 1280×720 を基準に、スマホ・タブレット・PC の画面に合わせて拡大・縮小します。

## Netlify に公開する

### A. いちばん簡単：ドラッグ＆ドロップ
1. https://app.netlify.com/drop を開く
2. この **フォルダごと**（index.html がある階層）をドラッグ＆ドロップ
3. 出てきた URL をスマホで開けば遊べます

### B. おすすめ：GitHub と連携（更新が楽）
1. このフォルダを GitHub のリポジトリに入れる
2. Netlify → Add new site → Import an existing project → リポジトリを選ぶ
3. 設定は `netlify.toml` に書いてあるので、そのまま Deploy
   - デプロイのたびに `tools/make_manifest.py` が動き、画像の一覧（assets/manifest.json）を自動で作ります
   - 以後は GitHub に push するだけで 更新されます

※ index.html を ダブルクリックで開くだけでは 動きません（ブラウザの制限でデータを読めないため）。
手元で試すときは、このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000 を開いてください。

## ゲームの流れ

1. タイトル → おとこのこ・おんなのこ と色 → なまえ（画面上のひらがなキーボード）→ しょくぎょう
2. **いまの ようちえん**（チュートリアル）：園長先生 → なかよしバトル2ひき → 宝箱 → 報告でクリア
3. **ときの とびら**（スタンプカード）が開く：へいせい・しょうわ・はじまり を **好きな順で** 冒険
   - 各時代：案内役と話す → モンスター2ひきと なかよし → 報告で「えがおの かけら」とスタンプ
   - 1日1つずつ 遊んでも、いっきに 遊んでもOK（自動セーブ）
4. かけらが4つ そろうと **エンディング**（おいわいの きに はなが さく）

おもいでカードは 全14まい。1時代 3〜4分、全部で 15分前後です。

## 更新を アップロードするとき（だいじ）

ブラウザは 前に 読んだ ファイルを おぼえていて、更新しても 古い画面が 出ることが あります。
**アップロードの前に 毎回** `python3 tools/bump_version.py` を 実行してください。
URL に 新しい番号が つき（必ず 新しい ファイルが 読まれる）、画像の一覧 `assets/manifest.json` も 作りなおされます。
画像を 足したのに 出ないときは、この一覧の 作りなおし忘れです。
Claude から 受けとる zip は 実行ずみです。フォルダは **まるごと** 上書きしてください。

## フォルダ

```
index.html             入口
css/style.css          見た目
js/
  main.js              起動・画面の切り替え・画面サイズ合わせ
  data.js              data/*.json の読み込み
  game.js              進行状況・フラグ・カード・セーブ（ブラウザの localStorage）
  assets.js            画像/音の読み込み（無ければ仮素材）
  art.js               仮素材の絵（SVG）
  voice.js             音声ファイル再生 → 無ければ 読み上げ
  ui.js                ボタン・会話ウィンドウ・カード・ひらがなキーボード・ハート
  effects.js           ひっさつわざ などの演出
  screens/             title / hero / name / job / map / battle / zukan / clear
data/                  ゲームの中身（JSON）。文章・モンスター・カード・イベントはここで直す
assets/                画像と音（docs/ASSET_LIST.md の名前で置くと 差し替わる）
fonts/                 日本語フォント（使う文字だけに軽量化した Noto Sans CJK JP）

tools/make_manifest.py 画像の一覧を作る（Netlify では自動）
netlify.toml           Netlify の設定
```

## しくみ

- **画像の差し替え**：`assets/<種類>/<ID>.png` を置くだけ。無いときは コードで描いた仮素材が出ます。
  名前とサイズの一覧は `docs/ASSET_LIST.md`（ChatGPT さんに そのまま渡せます）。
  `js/assets.js` の `showPlaceholderNames: true` にすると、仮素材に ファイル名が表示されます。
- **データ管理**：キャラ・職業・コマンド・モンスター・カード・会話・イベントは `data/` の JSON。
  例：ハートの増え方は `data/commands.json` の `heart_good` / `heart_normal` / `heart_max`。
- **イベント**：`data/chapters/chapter1.json` の各オブジェクトの `events` を上から見て、`if` の条件に合う最初の1つが起きます。
  使えるキー：`dialogue`（会話）`set`（フラグ）`give_card`（カード）`battle`（モンスターID）`then: "chapter_clear"`。
- **音声**：会話の各行の `voice`（音声ID）の mp3 が `assets/voice/` にあれば再生、無ければ ブラウザの読み上げ。
  iPhone 対策として、最初のタッチで音を有効にしています。タイトル右上のスピーカーで オン／オフ。
- **セーブ**：イベントのたびに自動セーブ＋マップの「セーブ」ボタン。ブラウザの localStorage に保存
  （同じ端末・同じブラウザなら 閉じても続きから遊べます。シークレットモードでは消えます）。
- **確認用**：ブラウザの開発者ツールのコンソールで `YQ.Game.state` を見ると 進行状況が確認できます。

## 時代（とびら）の 中身を かえる・ふやす

- 各時代の 会話・モンスター・カードは `data/chapters/chapter2.json`（平成）`chapter3.json`（昭和）`chapter4.json`（はじまり）
- とびらの 並び・色・名前と、とびら画面／エンディングの 園長先生の セリフは `data/eras.json`
- 時代を ふやすときは `chapterN.json` を作り、`eras.json` の `eras` に1行 足すだけです（エンディングは「すべてクリア」で開きます）
- **カードや 会話の 歴史の 中身は 仮です**（実際の創立年・行事などは 園に確認して 書きかえてください）
