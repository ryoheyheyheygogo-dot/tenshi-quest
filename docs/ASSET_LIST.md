## 共通ルール

- 形式：PNG（背景以外は **背景透明**）。背景・大きな絵は WebP / JPG でも OK（`tools/bump_version.py` を実行すると 自動で 一覧に のります）
- ファイル名：下の表の「ID」＋ `.png`（例：`assets/monsters/sukikirai.png`）
- 画面サイズは 1280×720（横画面）。表の「表示サイズ」はゲーム内で表示される大きさです
- 画像は表示サイズの **2倍** で作ると、タブレットでもくっきりします（縦横比は合わせる）
- ドット絵は拡大してもぼやけない設定（pixelated）にしてあります。
  ドット絵ではない普通のイラストにする場合は、`css/style.css` の
  `.vis img { ... image-rendering: pixelated; }` を `image-rendering: auto;` に変えてください
- キャラクターは **正面向き・足元が画像の下端** にそろうように描いてください（マップで足元を基準に置くため）
- 地図の歩くキャラ（walk_）は **右向き**。左へ歩くときはゲーム側で反転します
- ドラゴンクエストの名前・ロゴ・モンスター・音楽に似せすぎないこと（オリジナルで）
